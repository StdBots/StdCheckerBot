## ⚡ Highlights & Key Features

- **🚀 Concurrency Engine:** Checks 100+ URLs in parallel using lightweight Goroutines with dynamic progress bars.
- **🌐 Proxy Diagnostic:** Supports HTTP, HTTPS, SOCKS4, and SOCKS5 proxies with IP echo & latency analysis.
- **🔐 Deep SSL & Header Analysis:** Evaluates SSL certificate validity, issuer, expiry countdown, and redirect chains.
- **📲 Telegram Link & Token Verifier:** Inspects invite links, public channels, and tests Bot Tokens via `getMe`.
- **📑 Dual Export Formats:** Automatically generates structured `.csv` and `.json` reports for direct download.
- **🛡️ 7-Layer Cryptographic Kernel:** Steganographic bit-vector integrity lock protecting author branding.
